# Renombrador de Fotografías / Photo Renamer

## Español

Aplicación web desarrollada con Streamlit para renombrar fotografías en dos modalidades:

- **Renombrar por completo:** crea nombres nuevos con numeración consecutiva.
- **Añadir texto al final:** conserva el nombre original y agrega un texto antes de la extensión.

La aplicación muestra una vista previa, solicita confirmación y genera un archivo ZIP descargable sin modificar el contenido de las fotografías.

### Ejecución local

```bash
pip install -r requirements.txt
streamlit run main.py
```

## English

Web application built with Streamlit to rename photographs in two modes:

- **Rename completely:** creates new names with consecutive numbering.
- **Append text:** keeps the original name and adds text before the extension.

The application shows a preview, asks for confirmation, and generates a downloadable ZIP file without modifying the photo contents.

### Local execution

```bash
pip install -r requirements.txt
streamlit run main.py
```
